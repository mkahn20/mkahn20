## Federated Learning with Variational Autoencoder for Popularity Profile Prediction
**IEEE / International Conference on ICT Convergence 2023**  
Oct. 13, 2023  
**Authors:** Minkyun Ahn, Minseok Choi

This work focuses on inferring regional content popularity distributions, personalization, and secure aggregation.  

It is a component of the IITP-U.S. collaborative research project.
